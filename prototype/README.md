# 创源印记 · 可交互产品原型（网页版）

> AI奇点赛道 · 概念验证原型 · 单文件自包含，无需联网、无需登录

## 运行说明

1. 用任意现代浏览器（Chrome / Edge / 火狐）**直接双击打开本目录下的 `index.html`** 即可体验。
2. 无需安装任何软件、无需联网、无需注册登录；页面内置全部样式、脚本与图片素材。
3. 手机 / 平板亦可访问，桌面端体验最佳。

## 原型包含的核心功能模块

| 模块 | 体验方式 |
| --- | --- |
| 创作模拟区 | 输入创意（或点击示例）→ 点「开始AI生成」→ 观看生成过程与「原生指纹即时嵌入」 |
| 过程溯源区 | 生成完成后点击「查看过程溯源」→ 查看创作决策链与「人机贡献度量化」（创作者62% / AI 38%） |
| 一键验证区 | 选择示例作品 → 点「开始一键验证」→ 输出创作者身份、生成时间、原创性核验报告 |
| 对比确权模块 | 横向对比「传统水印 / 区块链存证 / 创源印记」，突出智能化颠覆点 |
| 自动演示 | 右上角「自动演示全流程」按钮，约60秒自动走完核心功能，适合评审快速了解 |

## 演示数据说明

本原型为**概念验证**（POC），所有生成内容、指纹 ID、验证结果、贡献度数据均为**前端模拟数据**，
用于完整演示「生成即确权 → 过程溯源 → 一键验证」的产品逻辑，不代表真实系统运行结果。
