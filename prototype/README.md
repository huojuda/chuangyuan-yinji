# 创源印记 · 可交互产品原型（网页版）

> AI奇点赛道 · 概念验证原型 · 前端单文件自包含；连接后端即为真实大模型生成

## 运行说明

原型有两种模式，**指纹计算与验证在两种模式下都完全真实**：

1. **直接双击打开 `index.html`（演示模式）**：无需联网、无需登录；AI 生成使用内置示例文案，SHA-256 指纹、确权登记、上传比对仍为浏览器本地真实计算。
2. **连接后端（真实 AI 模式，推荐）**：在仓库根目录执行：
   ```powershell
   cd server
   $env:DEEPSEEK_API_KEY="sk-你的密钥"
   python app.py        # Python 3.8+，零依赖
   # 浏览器打开 http://localhost:8090
   ```
   也可在页面左下角「配置后端地址」中指定服务地址；部署到 Vercel 的方法见 `../server/README.md`。

## 核心功能模块（均可真实操作）

| 模块 | 体验方式 |
| --- | --- |
| 创作模拟区 | 输入创意 → 点「开始AI生成」→ 真实调用 DeepSeek（或降级示例文案）→ 浏览器计算 **真实 SHA-256 指纹**并派生指纹 ID |
| 过程溯源区 | 查看创作决策链与**动态人机贡献度**（随本次提示词与成品长度变化，非固定值） |
| 一键验证区 | 选示例 / 选「我刚创作的作品」/ **上传本地文件** → 本地算 SHA-256 与确权库逐位比对；命中出通过报告，未登记如实告知 |
| 技术原理区 | 三层架构（内容指纹 / 行为特征 / 验证共识）与截图、压缩、裁剪、AI 洗稿等六类攻击的工程应对 |
| 对比确权模块 | 「传统水印 / 区块链存证 / C2PA / 创源印记」四维对比，突出智能化颠覆点 |
| 立场与伦理 | 态度宣言、四类风险应对与「工具内嵌 → 平台接入 → 交易分账」三步破局路径 |
| 自动演示 | 右上角按钮，约 60 秒自动走完全部板块 |

## 推荐的真实性验证动作

1. 连接后端，输入任意创意生成一件作品，记录其 SHA-256 指纹；
2. 点「下载确权作品」得到 `.txt`，**原样上传** → 核验通过、指纹逐位一致；
3. 用记事本把该文件**改动一个字**再上传 → 因哈希雪崩效应判定「未在确权库登记」，系统不做假。

## 数据与隐私说明

- 作品确权登记保存在浏览器 localStorage；验证时**文件仅在本地计算哈希，不上传文件内容**；
- DeepSeek 密钥只存在于后端环境变量，前端不含任何密钥；
- 鲁棒隐写、跨模态语义核验、多节点共识为面向生产环境的技术设计，本原型以可交互方式演示其完整闭环。

## 技术备注

前端为单文件 HTML + 原生 CSS/JS，通过 Web Crypto API（`crypto.subtle.digest('SHA-256')`）计算指纹；后端 `server/app.py`（本地）与 `api/generate.py`（Vercel）均为零第三方依赖实现。
