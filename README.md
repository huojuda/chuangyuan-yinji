### 本地运行（真实 AI，零第三方依赖）

```powershell
cd server
$env:DEEPSEEK_API_KEY="sk-你的密钥"   # 仅存在于服务端环境变量，不进前端、不进 git
python app.py                          # Python 3.8+，无需 pip install
# 浏览器打开 http://localhost:8090
```

Vercel Serverless 版本见 `api/generate.py` 与 `vercel.json`，在 Vercel 控制台配置环境变量 `DEEPSEEK_API_KEY` 即可。

## 核心功能（均可真实操作）

- **真实大模型生成**：输入创作意图，后端调用 DeepSeek 现场生成短诗 / 视觉方案 / 广告文案，记录模型、耗时与 token。
- **真实 SHA-256 内容指纹**：生成完成后浏览器用 Web Crypto API 对成品逐字节计算 SHA-256，指纹 ID 由哈希派生，可重复验证。
- **真实验证闭环**：作品写入浏览器确权登记库（localStorage）；「下载确权作品 → 原样上传」验证通过，**改动一个字即因哈希雪崩效应判定未登记**，系统如实告知、不做假。
- **动态人机贡献度**：不按字数，而按创意决策加权；「生成迭代」节点的 AI 占比随本次提示词与成品长度真实变化。
- **确权凭证导出**：验证后生成可保存的 HTML 凭证，含创作者、指纹、登记时间与核验结论。

## 技术差异化

传统水印是「贴标签」（可裁剪）、区块链是「存证单」（链上存哈希、内容仍分离）、C2PA 是「元数据凭证」（转码易剥离、不区分人机贡献）；
创源印记把确权**织入 AI 创作本身**：生成瞬间原生嵌入、决策节点全量溯源、跨模态核验、开源协议兼容 C2PA。

## 安全说明
